# recalling

Remembers situations met before (glossary: [almanac](../../../docs/glossary/almanac.md),
patterning). Given the events so far, it says what usually came next, with
the probability counted from every known chain, and which known chains
hold those events, with the cataclysm they came to and its solution.

Steps: `read` (the project's almanac, then the universal one) → `predict` →
`recall`.
