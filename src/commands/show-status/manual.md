# show-status

`show-status [subject]`

- `workshop` (default) — active workshop root and the state of each area from `config/workshop.json`
- `workshops` — every workshop on this machine (`~/__WORKSHOP`, `/media/**/__WORKSHOP`), active one marked `*`
- `forge`, `archive` — directories inside that area
- `interfaces` — loaded interfaces
- `tree` — raw dump of the loaded workshop model tree
